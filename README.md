# Muhad K - Portfolio Website

A modern, data-driven portfolio website showcasing expertise in software engineering, data science, and sports technology. Built with cutting-edge web technologies for performance and user experience.

## Tech Stack

- **Vite** - Lightning-fast build tool and dev server
- **React 18** - UI library with hooks and concurrent features
- **TypeScript** - Type-safe development
- **shadcn/ui** - High-quality, accessible component library
- **Tailwind CSS** - Utility-first styling
- **React Router** - Client-side routing
- **Framer Motion** - Smooth animations and transitions
- **TanStack Query** - Data fetching and caching

## Quick Start

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd muad-website

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will open at `http://localhost:8083`

### Build

```bash
# Production build
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/      # Reusable React components
├── pages/          # Page components (Index, CV, Blog, etc.)
├── assets/         # Images and media files
├── App.tsx         # Main app component with routing
└── index.css       # Global styles
```

## Features

- Responsive design for all devices
- Smooth animations and transitions
- Interactive components with Framer Motion
- Font variation animations (TextPressure component)
- Dark mode support with next-themes
- Type-safe development with TypeScript
